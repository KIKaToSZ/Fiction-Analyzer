      这俩凭证是干什么的？

      填写后，本工具会用 App ID + App Secret 调飞书 OpenAPI，把你指定的飞书多维表格里的「章节正文」子表自动拉进页面。打开页面就能看到最新内容，不用每次手动导入。

      首次配置只需 3 步： ① 去 飞书开放平台 创建一个「企业自建应用」，复制它的 App ID 和 App Secret 填到下面 ② 在应用的「权限管理」里开通 bitable:app:readonly（多维表格只读权限） ③ 把多维表格「分享给该应用」（表格右上角 ··· → 添加文档应用）

      安全 凭证只存在你当前浏览器的 localStorage，不会上传任何服务器；不要把页面分享给同事用同一份凭证。 查看飞书多维表格 API 文档

      仅保存在本地浏览器；用于获取 tenant_access_token 调飞书 OpenAPI。

      多维表格中作为「章节正文」的子表名（精确匹配）。

      导入表格数据

      在飞书多维表格中选中要导入的行（章节号 / 章节名 / 文章内容 三列），Ctrl/Cmd+C 复制后粘贴到下方文本框。 支持 Tab / 逗号 / 多空格分隔，可勾选「跳过首行表头」。
