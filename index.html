          选择一个本地 .xlsx 或 .json 文件。xlsx 按 sheet 名的特征自动归类到对应页面（章节 / 伏笔管理 / 后续扩展），可以手动指定；json 是数组格式的章节或伏笔数据，每项是一个对象、keys 作为列名。文本粘贴（Tab / 逗号 / 多空格 / JSON 数组）作为兜底，默认导入到「章节」页。

          点击选择 / 拖入 .xlsx 或 .json 文件
          支持 .xlsx / .xlsm / .json 格式（json 为数组格式），单文件

          打开文件

          把本地 .xlsx 或 .json 文件拖入下方区域，或点击区域选择。xlsx 表头需包含：章节号 / 章节名 / 文章内容 三列；json 是应用之前导出的快照。
          提示：日常保存自动写 json（不会丢数据），但 xlsx 不会被自动写回——拖入时读取的合并 / 超链接 / 列宽 / 其他 sheet 等格式只在你点「导出 xlsx」时才会写回原文件。原始 xlsx 的句柄也不持久化，关闭页面后浏览器不再记得它。
