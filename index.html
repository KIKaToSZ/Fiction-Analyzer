      导入 xlsx 条目

      选择一个本地 .xlsx 文件。系统会按 sheet 名的特征自动归类到对应的页面（章节 / 伏笔管理 / 后续扩展），也可以手动指定。文本粘贴仅作为兜底，默认导入到「章节」页。

      点击选择 / 拖入 .xlsx 文件
      支持 .xlsx / .xlsm 格式，单文件
      或粘贴文本（Tab / 逗号 / 多空格分隔）
      每行会根据 sheet 名的特征自动归类，可以手动改

      打开文件

      把本地 .xlsx 或 .json 文件拖入下方区域，或点击区域选择。xlsx 表头需包含：章节号 / 章节名 / 文章内容 三列；json 是应用之前导出的快照。
      提示：拖入的文件仅本次会话内可访问，关闭页面前请用「导出 json」或「导出 xlsx」手动备份。

      点击选择 / 拖入 .xlsx 或 .json 文件
      支持 .xlsx / .xlsm / .json 格式，单文件

      打开文件夹

      从本地选择一个文件夹。系统会列出其中所有 .xlsx / .xlsm 文件并加入「最近打开」列表。
